# 테라리움 사용자 가이드

> 동작하는 화면을 문서 안에 통째로 담아, 그 위에 Comment 를 달아 주고받는다.

이 문서는 두 부분이다. **1부 컨셉**은 테라리움이 무엇이고 왜 이렇게 생겼는지, **2부 사용법**은 화면을 담고 Comment 를 달고 주고받는 방법이다. 기획자(작성하는 사람)와 받는 사람이 같이 읽도록 썼다.

---

# 1부 · 컨셉

## 1. 왜 테라리움인가

바이브 코딩으로 high-fi 화면을 몇 분 만에 만들 수 있게 됐다. 그런데 그 화면을 사람에게 설명하고 의견을 받는 일은 여전히 캡처 이미지에 묶여 있다.

- 화면을 고칠 때마다 캡처를 다시 뜨고, 슬라이드에 붙이고, 박스를 치고, 번호를 맞춘다.
- 캡처로는 화면이 **어떻게 움직이는지**(탭 전환, 정렬, 차트 갱신, 캔버스 클릭)를 보여 줄 수 없다.
- 피그마 같은 도구는 이미 코드로 만든 화면을 다시 그려야 하고, 받는 사람에게 계정과 클라우드를 요구한다.

화면은 살아서 움직이는데 그 화면을 설명하는 문서는 정지된 그림이다. 테라리움은 이 어긋남을 없앤다. 유리 용기 안에 살아 있는 생태계를 통째로 담아 건네듯, **동작하는 화면을 문서 안에 완결된 채로 담는다.**

## 2. 두 가지 — 프로그램과 문서

| | 테라리움 프로그램 | 테라리움 문서 (`.terr.html`) |
|---|---|---|
| 누가 | 기획자 · 작성자 | 받는 사람 누구나 |
| 무엇 | 화면을 담고, Comment 를 달고, 버전을 관리하고, 돌아온 의견을 합친다 | 화면이 실제로 돌고, Comment 가 보이고, 답글·체크를 달아 돌려보낸다 |
| 필요한 것 | 프로그램 | **아무것도 없다.** 크롬·엣지로 더블클릭 |

빵집과 빵에 비유할 수 있다. 프로그램은 빵을 굽는 빵집이고, 문서는 구워져 나온 빵이다. **빵집이 없어도 빵은 먹을 수 있다** — 문서 하나에 화면 재생, Comment 보기, 답글, 저장이 모두 들어 있다. 서버도 계정도 필요 없다.

## 3. 문서의 문서

테라리움 문서는 화면정의서를 **품은** 문서다.

```
OHT모니터링 화면정의서.terr.html
├── 보기·편집 코드        화면 표시 · 마커 · Comment · 답글 · 저장
├── 문서 데이터            제목 · 버전 · 변경 이력 · 참여자
│   └── 화면들
│       └── SCR-001 OHT 실시간 모니터링
│           ├── v1, v2 …    원본 HTML·JS·데이터·이미지를 폴더째 그대로
│           ├── 자유 노트    마크다운 탭들 (화면의 어느 자리에도 묶이지 않는 글)
│           └── Comment     대상 요소 · 위치 · 본문 · 답글 · 달 때 찍은 화면 · 클립
└── 원본 파일들(내용 해시로 한 번만)
```

- 원본 화면은 **건드리지 않는다.** 열 때마다 문서 안에서 실제로 실행된다. 언제든 꺼내 다시 쓸 수 있다.
- 같은 파일은 버전이 달라도 한 번만 담는다(내용 해시). v1·v2 를 같이 넣어도 용량이 크게 늘지 않는다.
- 폰트·CDN 같은 외부 리소스도 담을 때 내려받아 넣는다. 받는 사람은 인터넷이 없어도 연다.

## 4. 품을 수 있는 화면

| 종류 | 무엇 | 편집기에서 | 받는 사람에게 |
|---|---|---|---|
| **화면 폴더** | HTML·CSS·JS·데이터로 된 프로토타입 폴더 | 실제로 돈다 | 똑같이 돈다 |
| **URL** | 실제 웹 사이트 | 편집기 안에서 실시간으로 돈다(로그인도 그 안에서) | 마지막 사본 + Comment 마다 달 때 찍은 화면 |
| **그림** | png · jpg 등 | 그림 | 그림 |
| **녹화 클립** | 화면의 움직임 (최대 60초) | Comment 에 붙는다 | 카드 안에서 반복 재생 |

URL 화면의 사본은 서버와 주고받던 동작이 멈춘다. 지도처럼 캔버스·WebGL 로 그린 부분은 픽셀(그림)로 담긴다. 화면 안에서 혼자 도는 동작은 살아 있을 수 있다.

## 5. Comment — 화면 위에 붙는 의견

- **어디에** — 요소(버튼, 탭, 표의 칸)나 영역(캔버스·지도 위의 한 구역)에 붙는다. 화면이 바뀌어도 요소의 지문(id, 클래스, 위치, 글자)으로 다시 찾는다.
- **무엇을** — 마크다운 본문 하나와 마크다운 답글. 유형·상태·담당 같은 칸은 없다. 할 일은 `- [ ]` 체크박스로 적는다. 받는 사람도 체크박스는 누를 수 있다.
- **어떤 상태에서** — 탭을 넘기거나 캔버스를 눌러 들어간 화면(FAB 조망 → BAY-4 상세 맵), 다른 HTML 페이지에서 단 Comment 는, 그때 누른 길을 같이 기억한다. 나중에 그 Comment 를 누르면 **테라리움이 그 길을 다시 눌러 그 화면 상태로 데려간다.**
- **그 순간의 모습** — Comment 를 달 때 화면을 그림으로 찍어 같이 남긴다(§2부 6). 화면이 그 뒤로 재생되어 바뀌었어도 무엇을 가리켰는지 알 수 있다.

## 6. 주고받기 — 라이브 문서

```
기획자: 작업 폴더 ──자동──▶ dist/화면정의서.terr.html ──보낸다──▶ 받는 사람
                                                               │ 브라우저로 열어 답글·체크
기획자: 작업 폴더 ◀──병합── returned/화면정의서_홍길동.terr.html ◀──돌려보낸다──┘
```

- 고치면 **자동으로 저장**된다. "저장"은 지금 바로, "다른 이름으로 저장"은 사본이다.
- 받는 사람이 저장하면 파일 이름 뒤에 자기 이름이 붙는다. 돌아온 파일을 작업 폴더의 `returned/` 에 넣으면 "회신" 이 떠서 한 번에 합친다. 같은 Comment 를 둘이 고쳤으면 지우지 않고 답글로 남긴다.

# 2부 · 사용법

## 1. QUICK START

Node.js 20 이상

```sh
npm install
npm start
```
혹은 응용 프로그램

`npm start` 는 프로그램을 빌드해 `run/` 에 실행본을 만들고 그것을 띄운다. 켜 둔 프로그램은 다시 켤 때까지 바뀌지 않는다 — 새 버전을 받았으면(`git pull`) 창을 닫고 `npm start` 로 다시 켠다.

처음 켜면 이름을 묻는다. Comment·답글에 이 이름이 붙는다(툴바의 이름을 눌러 바꾼다).

## 2. 화면 구성

```
┌ 툴바 ─────────────────────────────────────────────────────────────────────────────┐
│ 🌱 [작업폴더 ▾][회신 1]  문서 제목 ⇔  v0.1      보기·피커   ↶ ↷   ▣ ☀ 이름 · 자동 저장됨 [저장|💾✎] │
├ 탭 ───────────────────────────────────────────────────────┬─┬───────────────────┤
│ SCR-001 OHT 모니터링 × │ SCR-002 지도 × │ ▾ ＋            │┃│ ▸ 자유 노트       │
├ 화면 막대 ─────────────────────────────────────────────────┤┃│ ───────────────── │
│ [v1][v2] 새 버전▾  index.html›detail.html    ● 실행 중 │ ⏸ ● ◐ │ − 맞춤 59% + ⤢ 🗑 │┃│ Comment 3     ＋  │
├────────────────────────────────────────────────────────────┤┃│ ⠿ ① 이름 · 방금   │
│                                                            │┃│ ⠿ ② 다른 상태     │
│                  화면 (실제로 동작)                          │┃│ ⠿ ③ …             │
│                  ① ② ③ 마커                                 │┃│                   │
└────────────────────────────────────────────────────────────┴─┴───────────────────┘
```

| 자리 | 하는 일 |
|---|---|
| **툴바** | 문서 수준 — (저장 옆 디스켓·연필 단추가 다른 이름으로 저장) 작업 폴더·문서 열기, 회신, 문서 제목과 버전, 보기/피커, 되돌리기, 패널, 테마, 이름, 저장 |
| **문서 제목 칸** | 마우스 휠을 위로 굴리면 넓어지고 아래로 굴리면 좁아진다. 오른쪽 끝을 끌어도 되고, 더블클릭하면 원래 폭 |
| **탭** | 열어 둔 화면들. 눌러서 오가고, **두 번 눌러 화면 이름을 바꾸고**, 끌어서 순서를 바꾼다. **×**(또는 가운데 클릭)는 그 화면을 **지운다** — 한 번 묻고 지우며 `Ctrl+Z` 로 되돌린다(받는 사람은 지울 수 없어 탭만 닫힌다). **▾** 는 문서의 모든 화면 목록(탭으로 안 연 화면이 있으면 개수가 뜬다), **＋** 는 화면 추가 |
| **화면 막대** | 지금 화면의 버전 칩(누르면 그 버전), 새 버전, 지금 페이지(누르면 첫 페이지로), 실행 상태, 일시정지 · 녹화 · 마커 색, 여백 / 꽉 채움, 배율, 전체화면, 화면 지우기 |
| **마커 줄** | 화면 막대 아래. 지금 화면 버전의 Comment 번호 ①②③… 를 늘어놓는다. 누르면 그 Comment 가 열린다. 모양으로 구분한다 — **주황 원**: 지금 화면에 붙어 보인다 · **점선 원**: 다른 상태(누르면 그 상태로 찾아간다) · **📷 네모**: 캡처 · **점선 네모**: 화면 전체 |
| **오른쪽 패널** | 위에 **자유 노트**, 아래에 Comment 목록. 둘 다 제목을 눌러 접고 편다. 자유 노트는 기본으로 접혀 있고, 펼치면 패널의 절반을 차지한다(길어지면 그 안에서 스크롤). 사이를 끌어 높이를 바꾸고, 더블클릭하면 다시 절반. 패널과 화면 사이 손잡이로 패널 폭을 바꾼다 |
| **자유 노트** | 화면의 어느 자리에도 묶이지 않는 글 — 화면 설명, 회의록, 데이터 매핑 같은 것. 탭을 여러 개 둔다: **＋** 로 탭을 더하고, 탭 이름을 두 번 눌러 이름을 바꾸고, 탭의 × 로 지운다(한 번 묻는다). 첫 탭을 지우면 다음 탭이 첫 탭이 되고, 하나뿐인 탭을 지우면 내용만 비운다 |
| **터미널** | 창 맨 아래 "터미널" 줄. 누르거나 `` Ctrl+` `` 로 펴고 접는다(§12) |

**실행 상태**는 화면이 지금 어떤지 알려 준다 — ● 실행 중 / 실시간 사이트(URL) / 일시정지 / 멈춤 · 고르는 중(피커) / 녹화 중 / 그림.

**전체화면**(⤢) — 지금 화면만 모니터를 꽉 채운다. 탭 · 툴바는 숨고, 화면 막대 · 마커 줄은 **위쪽 끝**에 마우스를 대면 뜬다. 오른쪽 패널은 **오른쪽 끝**에 마우스를 대면 화면 위로 뜨고, 패널의 📌(고정)을 누르면 옆에 붙어 화면이 그만큼 줄어든다. `Esc` 로 나간다.

**새로 고침**(↻) — URL 화면은 사이트를 지금 모습으로 다시 불러오고, 폴더 화면은 처음 상태로 돌린다. 테라리움 프로그램의 URL 화면은 늘 실제 사이트가 도는 것이라 사이트가 바뀌면 그대로 보인다(이미 단 캡처는 그때 모습 그대로 남는다).

**여백 / 꽉 채움** — 여백은 화면을 비율 그대로 두고 둘레에 여백을 둔다. 꽉 채움은 여백 없이 탭을 가득 채운다(폭은 화면의 기준 폭에 맞추고, 높이는 탭에 맞춰 화면이 다시 배치된다. 그림 화면은 비율 그대로 크게).

**배율** — `−` `+` 로 한 단계씩, `Ctrl+휠`(화면 바깥 여백에서)이나 `Ctrl+=` / `Ctrl+-` 로도 바꾼다. 배율 칸을 누르거나 `Ctrl+0` 이면 "맞춤". 크게 키우면 스테이지가 스크롤된다.

## 3. 작업 폴더

테라리움은 VS Code 처럼 **폴더 하나**에 연결해서 일한다. 첫 화면의 **폴더 열기**로 고른다. 비어 있지 않아도 된다.

| 고른 폴더에 | 테라리움은 |
|---|---|
| 작업 폴더(`terrarium.json`)가 있으면 | 그대로 연다 |
| 테라리움 문서(`.terr.html`)가 있으면 | 그 문서를 풀어 그 폴더를 작업 폴더로 만든다(여럿이면 고른다) |
| 프로토타입(HTML)이 있으면 | 그 폴더를 작업 폴더로 하고 화면 등록 창을 연다 |
| 그 밖(빈 폴더 포함) | 새 작업 폴더로 시작한다 |

**URL 열기** — 작업 폴더 메뉴(툴바 왼쪽의 폴더 이름)나 첫 화면, 파일 메뉴의 **URL 열기…** 로 웹 주소 하나를 그 자체로 문서로 연다. 지금 문서에 탭을 더하는 것이 아니다. 작업 폴더는 고를 필요 없이 프로그램 안에 저절로 생기고, 같은 주소를 다시 열면 거기서 이어서 연다. 작업 폴더 메뉴의 **최근 URL** 에서 다시 연다. 주소에 담기지 않는 것(Comment · 노트 · 사본 · 달 때 찍은 그림)은 그 안쪽 작업 폴더에 담긴다.

작업 폴더 안에는 이런 것이 생긴다. 원래 있던 파일은 건드리지 않는다.

```
작업 폴더/
├── terrarium.json         문서 정보 · 화면 순서
├── screens/SCR-001/       화면 정보 · 자유 노트(notes.md, notes-<탭>.md) · Comment(comments.json)
├── blobs/                 원본 파일들
├── returned/              돌아온 회신본을 넣는 곳
└── dist/제목.terr.html    보낼 파일 — 늘 최신으로 자동으로 구워진다
```

- 켜면 첫 화면에 **최근** 목록(작업 폴더 · URL · 문서)이 뜬다. 저절로 열지는 않는다. 고르면 그 폴더의 보던 화면으로 열린다.
- **문서 열기**로 `.terr.html` 하나만 열 수도 있다. 그 파일에 바로 저장되고, "작업 폴더로 풀기"를 누르면 그 문서가 든 폴더(또는 고른 폴더)에 풀어 이어서 작업한다.
- 창에 폴더·문서·그림을 끌어다 놓아도 된다.

## 4. 화면 담기

탭 줄의 **＋**(화면 추가)에서 고른다.

- **화면 폴더 선택…** — 프로토타입 폴더(예: `example/proto`). 시작 파일(index.html)과 넣을 파일을 확인하고 등록한다. 원본 폴더가 바뀌면 "새 버전으로 등록할까요?" 를 띄운다.
- **URL…** — 주소를 넣으면 편집기 안에서 실제 사이트가 돈다. 로그인이 필요하면 그 안에서 하면 된다(다음에도 기억한다).
- **파일 — 테라리움 문서 · 그림…** — 여러 개를 한 번에 고를 수 있다.
  - **다른 테라리움 문서**(`.terr.html`) 를 고르면 그 안의 화면들이 버전 · 자유 노트 · Comment 째로 이 문서에 들어온다(화면 번호는 새로 매긴다).
  - **그림**(png · jpg) 은 그림 크기 그대로 화면이 된다. 한 장씩 화면이 된다.
  - 작업 폴더가 열려 있을 때 테라리움 문서를 창에 끌어다 놓아도 그 화면들을 가져온다(알림의 "대신 그 문서 열기" 로 그 문서를 따로 열 수도 있다).

같은 화면의 새 모습은 화면 막대의 **새 버전 ▾** 으로 등록한다. "기존 Comment 를 새 버전으로 옮기기"를 고르면 Comment 가 따라온다. 버전 칩(v1, v2)을 눌러 옛 화면을 그대로 다시 볼 수 있다.

## 5. Comment 달기

1. **`Ctrl` 을 누른 채** 요소를 클릭하거나, 영역을 드래그한다. (툴바의 **피커**(스포이드)를 켜 두면 Ctrl 없이도 된다.)
   - 누르는 순간 화면이 **멈춘 그림**으로 덮인다 — 움직이는 화면에서도 고를 수 있다.
   - 고르는 동안 `↑` `↓` 로 감싸는 요소 / 안쪽 요소로 옮긴다.
   - 그림 화면은 요소가 없다 — 클릭하면 작은 박스, 드래그하면 그린 박스.
   - **영역을 드래그하면** 작성 창 위에 윈도우 캡처 도구 같은 단추가 뜬다(테라리움 프로그램에서):
     - **캡처**(기본) — 그 영역을 그림으로 남긴다. 실시간 화면에는 마커가 붙지 않고, 열면 찍어 둔 그림과 박스가 보인다. 마커 줄에는 📷 로 표시된다.
     - **녹화** — 누르는 동안 화면이 다시 돌고, 그린 영역만 녹화한다(최대 30초). 멈추면 클립이 작성 창에 붙는다.
     - **화면에 붙이기** — 실시간 화면의 그 자리에 마커를 붙인다(지도·캔버스의 한 구역처럼 계속 가리켜야 할 때).
     - 받는 사람 브라우저에서는 화면을 찍을 수 없어 드래그한 영역도 화면에 붙는다.
   - **URL 화면은 요소를 클릭해도 캡처가 기본이다.** 사이트는 언제 어떻게 바뀔지 모르기 때문이다. 계속 가리켜야 하면 "화면에 붙이기" 를 고른다. 사이트 안에서 주소가 바뀌면(페이지를 다시 불러오지 않는 사이트도) 그 주소에서 단 마커만 붙는다.
2. 대상 옆에 뜬 작성 창에 **제목**(없어도 된다)과 **마크다운** 본문을 쓴다. 제목을 달았으면 본문은 비워 둬도 된다. `Ctrl+B` 굵게, `Ctrl+I` 기울임, `- [ ]` 체크박스, Enter 로 목록 이어 쓰기.
   - 제목과 내 이름은 패널 카드의 첫 줄과 화면의 마커 옆에 보인다. 마커 옆 이름표가 거슬리면 마커 색(◐) 메뉴의 **번호 옆에 제목 · 이름 보이기** 를 끈다.
3. **`Ctrl+Enter`** 로 추가. 마커(① ② ③)가 붙는다.

화면 전체에 대한 의견은 패널 Comment 제목 옆 **＋** 로 단다(마커 없이 목록에만).

## 6. Comment 보기 — "달 때 찍은 화면" 과 "지금 화면"

Comment 를 누르면(마커 또는 패널 카드) 대상 옆에 팝업이 뜬다. 제목 · 본문을 고치고 답글을 단다. 팝업은 오른쪽 아래 모서리를 끌어 크기를 바꾼다. 영상(클립)이 붙은 Comment 는 처음부터 크게 뜬다. 다른 대화상자도 모서리로 크기를 바꾼다.

**Comment 를 달 때 찍은 화면.** Comment 에 그 순간의 그림이 있으면, 열었을 때 스테이지에 **그 그림과 박스가 먼저** 보이고 아래에 *"Comment 를 달 때 찍은 화면 · 3시간 전  [지금 화면 보기]"* 가 뜬다.

- 테라리움이 판단해서 고르는 것이 아니다. 규칙은 하나다 — **그림이 있는 Comment 를 열면 그림부터 보인다.** 화면은 살아서 계속 바뀌니(실시간 지도, 시계, 갱신되는 표), Comment 가 가리키던 그때 그 모습을 먼저 보여 주는 것이다.
- **지금 화면 보기**를 누르면 그림을 걷고 지금 돌고 있는 실제 화면이 보인다. 마커는 지금 화면의 요소 위에 붙어 있다.
- 받는 사람이 브라우저에서 단 Comment 에는 그림이 없다(브라우저는 화면을 찍을 수 없다). 그럴 땐 바로 지금 화면이다.

**팝업 닫기.** 팝업의 × 는 **팝업만** 닫는다 — Comment 선택(카드 강조, 마커 강조)은 그대로다. 같은 카드나 마커를 다시 누르면 팝업이 다시 뜬다. 선택까지 풀려면 카드 제목을 한 번 더 누르거나 `Esc` 를 두 번 누른다.

**다른 상태의 Comment.** 지금 화면에서 대상이 안 보이는 Comment 는 패널에서 흐리게, "다른 상태" 로 표시된다. 누르면 테라리움이 그때의 길(탭 클릭, 캔버스 클릭, 다른 페이지)을 다시 눌러 그 화면으로 간다. 처음부터 다시 눌러야 하면 화면을 다시 불러오느라 잠깐 걸린다.

**순서 · 지우기.** 카드 왼쪽 ⠿ 을 끌어 순서를 바꾼다(번호가 따라 바뀐다). 고른 Comment 는 **`Delete`** 로 지운다. `Ctrl+Z` 로 되돌린다. 남이 단 Comment 는 작성자(테라리움 프로그램)만 지울 수 있다.

## 7. 녹화

화면 막대의 ●를 누르면 스테이지만 녹화한다(최대 60초). 다시 누르면 멈추고, 고른 Comment 에 클립이 붙는다(고른 것이 없으면 새 Comment 를 만든다). 브라우저에서는 "이 탭 공유"를 고른다.

## 8. 저장과 보내기

- 고치면 1초쯤 뒤 **자동 저장**. 툴바에 "자동 저장됨 · 방금" 이 보인다.
- **저장**(`Ctrl+S`) — 지금 바로 저장하고 `dist/` 의 보낼 파일을 다시 굽는다. 알림의 "폴더 열기" 로 그 파일 위치를 연다.
- **다른 이름으로 저장**(`Ctrl+Shift+S`, 저장 옆 단추) — 원하는 곳에 사본.
- 보낼 파일은 **`dist/제목.terr.html` 하나**다. 메일·메신저로 그대로 보낸다.

## 9. 받는 사람

1. 받은 `.terr.html` 을 **크롬이나 엣지**로 연다(더블클릭). 처음에 이름을 묻는다.
2. 화면을 그대로 조작해 본다. 탭 **▾** 에서 다른 화면을 연다.
3. Comment 를 눌러 보고, 답글을 달고, 체크박스를 누른다. **URL 화면**은 사이트를 띄울 수 없으니 Comment 를 달 때 찍은 그림과 녹화한 클립의 **모음**으로 보인다. 하나를 누르면 크게 펼쳐 본문 · 답글을 본다. 위쪽의 "마지막 사본 보기" 로 마지막에 담아 둔 사이트 모습을 볼 수도 있다. 새 Comment 도 단다(Ctrl+클릭).
4. 고친 내용은 이 브라우저에 자동으로 남는다 — 같은 파일을 다시 열면 이어서 열린다.
5. **저장**을 누르면 `원래이름_내이름.terr.html` 로 저장된다. 이 파일을 보낸 사람에게 돌려보낸다.
   - "파일에도 자동 저장" 을 한 번 누르면, 그 뒤로는 고칠 때마다 그 파일에도 자동으로 쓴다(크롬·엣지).

## 10. 돌아온 문서 합치기

돌아온 파일을 작업 폴더의 `returned/` 에 넣는다. 툴바에 **회신 1** 이 뜬다. 눌러서 **병합**하면 새 Comment·답글·체크가 들어오고, 합친 파일은 `returned/merged/` 로 옮겨진다. 같은 Comment 를 양쪽에서 고쳤으면 지우지 않고 답글로 남긴다.

## 11. 단축키

| 키 | 하는 일 |
|---|---|
| `Ctrl` + 클릭 / 드래그 | 요소 / 영역 고르기 |
| `↑` `↓` (고르는 중) | 감싸는 요소 / 안쪽 요소 |
| `Ctrl+Enter` | Comment · 답글 추가 |
| `Delete` | 고른 Comment 지우기 |
| `Esc` | 작성 취소 → 팝업 닫기 → 선택 풀기 → 피커 끄기 → 전체화면 나가기 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 되돌리기 / 다시 실행 |
| `Ctrl+S` / `Ctrl+Shift+S` | 저장 / 다른 이름으로 저장 |
| `Ctrl` + 휠 (화면 바깥) · `Ctrl+=` / `Ctrl+-` | 배율 |
| `Ctrl+0` | 배율 맞춤 |
| 휠 (문서 제목 칸 위) | 제목 칸 폭 |
| 가운데 클릭 (탭) | 화면 지우기 (한 번 묻는다) |
| `F12` · `Ctrl+Shift+I` | 개발자 도구 (프로그램) |
| `` Ctrl+` `` | 터미널 펴기 / 접기 |
| `F1` | 사용자 가이드 |

## 12. 터미널과 Claude Code

창 맨 아래 **터미널** 줄을 누르거나 `` Ctrl+` `` 를 누르면 VS Code 처럼 셸(Windows 는 PowerShell)이 펴진다. 지금 작업 폴더에서 시작한다. 위쪽 가장자리를 끌어 높이를 바꾸고, 접어도 셸은 그대로 살아 있다.

- **Claude Code** — 그 작업 폴더에서 `claude` 를 띄운다. 작업 폴더의 파일 형식(어느 파일이 Comment · 노트인지, 무엇을 고쳐도 되는지)을 알려 주며 띄우므로 "3번 Comment 에 답글 달아 줘", "회의록 탭 정리해 줘" 처럼 시키면 된다. (Claude Code 가 설치되어 있어야 한다.)
- **바깥에서 고치면 바로 다시 불러온다** — Claude Code 든 다른 편집기든 작업 폴더의 `comments.json` · `notes*.md` · `screen.json` · `terrarium.json` 을 고치면 테라리움이 잠깐 뒤 저절로 다시 불러온다. 알림의 **되돌리기**(또는 `Ctrl+Z`)로 되돌린다. 아직 저장하지 않은 고침이 있을 때는 덮어쓰지 않고 "다시 불러오기" 를 묻는다.
- **다시 불러오기** — 터미널 줄이나 보기 메뉴에서 손으로 다시 불러온다.
- **작업 폴더로** — 다른 작업 폴더를 열었으면 터미널 줄에 뜬다. 누르면 셸이 그 폴더로 옮긴다.

## 13. 개발자 도구

창 메뉴 **보기 → 개발자 도구**(또는 `F12` · `Ctrl+Shift+I`)로 연다. 콘솔·요소 검사로 테라리움 화면을 그대로 들여다볼 수 있다.

- URL 화면 안을 클릭해 둔 채 `F12` 를 누르면 그 **사이트의** 개발자 도구가 열린다.
- 창 메뉴: **파일**(폴더·문서 열기, 저장, 다른 이름으로 저장, dist·returned 폴더) · **편집**(되돌리기, 복사·붙여넣기) · **화면**(화면 추가, 새 버전, 피커, 일시정지) · **보기**(패널, 테마, 확대·축소·맞춤, 전체화면, 개발자 도구) · **도움말**(이 가이드 — 프로그램 안의 창으로 뜬다. 제목줄을 끌어 옮기고, 모서리로 크기를 바꾸고, A− / A+ 로 글자 크기를 바꾼다).

## 14. 자주 묻는 것

**화면이 하얗거나 "파일을 찾지 못했습니다" 가 뜬다.** 화면이 실행 중에 요청한 파일이 문서에 담기지 않았다. 아래쪽 안내의 "자세히" 에 빠진 파일 목록이 있다. 화면 폴더를 다시 등록할 때 그 파일을 포함한다.

**Comment 를 눌렀는데 그 화면으로 안 간다.** 그 Comment 를 달기 전에 누른 길이 너무 길었거나(최근 24번만 기억), 화면이 크게 바뀌어 같은 자리를 찾지 못했을 수 있다. 직접 그 화면으로 간 뒤 Comment 를 다시 달면 된다.

**URL 화면을 받는 사람이 보면 지도가 멈춰 있다.** 정상이다. 받는 사람에게는 마지막 사본이 간다 — 서버와 주고받는 동작은 멈추고, 캔버스는 그림으로 담긴다. 각 Comment 의 달 때 찍은 화면으로 그때 모습을 볼 수 있다.

**Firefox 에서 열리나?** 확인하지 않았다. 크롬·엣지를 쓴다.

**Comment 마커가 배경에 묻혀 안 보인다.** 화면 막대의 ◐(마커 색)에서 색을 고정한다. 기본(자동)은 마커 아래 배경 밝기에 맞춰 흑백을 고른다.
